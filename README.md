# MUBS Student Management System

Advanced Web Application Development (BUC3131) — Coursework Two (2026/2027)

---

## 1. Project Overview
The **MUBS Student Management System** is a web-based application built with **Laravel 11 / PHP 8.2** and **Bootstrap 5**. It provides role-based portal access for Administrators, Lecturers, and Students to manage student profiles, course offerings, and course registrations with authentication and authorization.
